# Web Element Locator Privacy Policy

Effective date: June 28, 2026

Publisher: Pantheon Network  
Web Element Locator helps you click a visible page element and copy a clear locator for describing where that element is.

## Data

When you start the extension and click an element, it may read local details for that clicked element: page path/hash, tag name, safe attributes, short visible text, owner region, optional selector, optional HTML excerpt, and optional viewport position.

The extension stores only your copy-field preferences in `chrome.storage.local`.

## Use

The data is used only to generate the locator copied to your clipboard.

## Sharing

Web Element Locator does not send, sell, transfer, or share user data with Pantheon Network or any third party. It makes no network requests and does not use telemetry, analytics, advertising, or remote code.

## Clipboard

The extension writes the generated locator to your clipboard after you click an element. It does not read clipboard contents.
